# WordSearch Game
1. Project Overview

Word Search game is an interactive browser-based game developed as a part of CST2120 Web Application and Databases coursework. 
The game allows user to register, login and play multiple levels of word search puzzle. players earn points by finding the words hidden in letter grid. players can also have access to leaderboard where they can see their ranking as comparison with other players. The project was developed using:
- HTML
- CSS
- JavaScript (ES2020+)

2. Technologies Used
- HTML:
Structure the website and game pages
- CSS:
Desinging, styling and layout.
- LocalStorage:
Stores registered user information and game scores in JSON format.
- HTML Audio:
Provides sounds effects during gameplay.

3. Main Features
User Accounts
- User registration
- User login
- Form validation
- Duplicate email and username checking
- User information stored in local storage
Word Search Game
- Interactive letter grid
- Multiple game levels
- Hidden words to discover 
- Score system: 10 points for each correctly found word
- visual feedback for correct or incorrect selections
- Sounds effects
- Level progression
Leaderboard 
- saves players score
- Displays player usernames and scores.
- Allows players to compare their results.

Website Navigation
- Homepage.
- Registration page.
- Login page.
- Game page.
- Leaderboard page.

4. How to run project?
- Download or extract the project folder
- open project in VS code
- Open index.html using modern we browser, or use live extension of VS code
- Navigate through home page
- Register a new account
- Login using your registered details
- start playing the game
- compete in levels and see your scores in leaderboard

5. Browser Compatibility
The project is designed to run in modern web browsers that support HTML5, CSS3, JavaScript ES2020+ and LocalStorage.
